# Спецификация: Раздел «Размеры и вес» (Справочник ГОСТ)

## Обзор
Создание полноценного справочного раздела для сайта «Железный Дровосек», содержащего таблицы теоретических весов и размеров металлопроката согласно ГОСТ. Дизайн должен соответствовать существующей эстетике Iron Woodman (темная тема, розовые акценты `#ffb0cc`, индустриальный стиль).

## Структура страниц

### 1. Главный хаб (`spravka.html`)
- **Заголовок**: «ИНЖЕНЕРНЫЙ СПРАВОЧНИК МЕТАЛЛОПРОКАТА»
- **Контент**: Сетка (Bento Grid) с категориями:
    - Арматура (А1, А3)
    - Балка (Двутавр)
    - Швеллер
    - Уголок стальной
    - Листовой прокат (Х/К, Г/К, ПВЛ)
    - Трубный прокат (Профильные, ВГП, ЭСВ)
    - Сортовой прокат (Квадрат, Круг, Полоса)
- **Функция**: Каждая карточка ведет на соответствующую страницу категории.

### 2. Страницы категорий (Пример: `spravka_armatura.html`)
- **Навигация**: «Хлебные крошки» (Справочник > Арматура).
- **Визуал**: SVG-чертеж профиля в шапке.
- **Таблица**:
    - Шапка таблицы фиксируется при скролле.
    - Столбцы: Номинальный размер, Масса 1 п/м (кг), Метров в тонне, Площадь сечения (опционально).
    - Интерактив: Подсветка строки при наведении.
- **Блок расчета**: Ссылка на калькулятор с предзаполненной категорией.

## Технические детали
- **Стек**: HTML5, Tailwind CSS (CDN), Material Symbols.
- **Компоненты**: Использование `js/shared-ui.js` для хедера и футера.
- **Данные**: Извлечение базовых весов из `products-data.js` и дополнение справочными данными ГОСТ.
