# Дизайн-спецификация: Светлая тема «Железный Дровосек»

**Дата:** 2026-05-18
**Статус:** На ревью

## 1. Цель
Реализовать полноценную светлую версию сайта (Light Mode), сохраняя премиальную, маскулинную идентичность бренда. Добавить переключатель тем в шапку сайта.

## 2. Визуальная концепция
Выбран вариант **"Champagne & Graphite"**:
- **Основной фон:** Теплый оттенок шампань/песок (#F2EFED).
- **Вторичные поверхности:** Мягкий графит (#32302E) и приглушенные металлические тона (#D7C1C7).
- **Акценты:** Сохраняется фирменный "индустриальный розовый" (#CA7093) для кнопок и важных элементов.
- **Текст:** Глубокий антрацит (#151311) для максимальной читаемости.
- **Формы:** Строгие прямые углы (0px radius), отсутствие теней (глубина через слои).

## 3. Техническая архитектура

### 3.1. Управление темой
- Переключение через класс на теге `<html>`: `<html class="dark">` или `<html class="light">`.
- Состояние сохраняется в `localStorage.getItem('theme')`.
- Логика инициализации и переключения выносится в `js/shared-ui.js`.

### 3.2. Цветовая палитра (Tailwind Config)
В каждом HTML-файле в `tailwind.config` будут добавлены переменные для светлой темы. 
Пример маппинга:
| Название | Dark (текущий) | Light (новый) |
| :--- | :--- | :--- |
| `background` | `#151311` | `#F2EFED` |
| `surface` | `#151311` | `#EBE8E6` |
| `on-surface` | `#e7e2dd` | `#151311` |
| `surface-container` | `#211f1d` | `#DEDAD7` |
| `primary` | `#ffb0cc` | `#CA7093` |

### 3.3. Компонент "Industrial Toggle"
Индустриальный ползунок в шапке (Shared Header):
- Прямоугольный корпус с рамкой 1px.
- Текстовые метки: `DARK` / `LIGHT`.
- Плавная анимация перемещения активного состояния.
- Размещение: рядом с иконкой личного кабинета или корзины.

## 4. Объем работ
1. Обновить `js/shared-ui.js`: добавить логику переключения темы и внедрения кнопки в DOM шапки.
2. Обновить `tailwind.config` во всех ключевых HTML-файлах для поддержки `light` варианта.
3. Добавить CSS-стили для светлой темы (обработка инверсии иконок, границ и специфических фонов).
4. Протестировать на страницах: Главная, Каталог, О компании, Контакты.
