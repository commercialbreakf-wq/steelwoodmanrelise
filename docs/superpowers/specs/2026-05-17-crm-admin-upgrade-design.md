# Дизайн-спецификация: Апгрейд панели управления до CRM-системы

**Дата:** 2026-05-17
**Статус:** На ревью
**Проект:** Железный Дровосек (Woodman Metal)

## 1. Обзор
Трансформация текущей админки в полноценную CRM-систему для управления продажами металлопроката. Основной фокус на интуитивности добавления товаров, управлении входящими заявками (лидами) и массовой обработке данных.

## 2. Архитектурные изменения
- **SPA (Single Page Application):** Переход на бесшовную навигацию между разделами без перезагрузки страницы.
- **Глобальное состояние:** Использование JS-объекта `adminState` для мгновенной фильтрации и поиска по товарам/заказам/лидам.

## 3. Функциональные возможности

### 3.1. Умный Мастер добавления товара (Wizard)
- **Шаг 1: Метод создания.** Выбор между "Новый товар" и "Клонировать существующий". Поиск для клонирования с автозаполнением всех последующих полей.
- **Шаг 2: Категория.** Выбор категории. Система определяет набор необходимых характеристик (Smart Forms).
- **Шаг 3: Характеристики.** Динамические поля ввода на основе категории (Диаметр для труб, Толщина для листов и т.д.).
- **Шаг 4: Цены и Медиа.** Ввод цены (Тонна/Ед), расчет веса, загрузка изображения.
- **Шаг 5: Предпросмотр.** Финальная проверка карточки перед сохранением.

### 3.2. Массовые действия с товарами
- **Интерфейс:** Чекбоксы в таблице товаров и плавающая панель действий ("Bulk Action Bar").
- **Операции:**
    - Изменение цен: +/- % или фиксированное значение.
    - Смена категории для группы товаров.
    - Массовое удаление.
    - Экспорт выбранных позиций в CSV/Excel (клиентская реализация).

### 3.3. Управление Лидами (CRM)
- **Новый раздел "Лиды":** Единая таблица для заявок с форм обратной связи, консультаций и корзин.
- **Поля:** Источник (форма), Имя, Телефон, Email, Сообщение, Статус (Новый, В работе, Завершен).
- **Бэкенд:** Новые эндпоинты `/api/admin/leads` (GET/PUT).

### 3.4. Аналитика и Дашборды
- **Кликабельные дашборды:** Карточки статистики на главной ведут в соответствующие разделы.
- **Блок Аналитики:**
    - График динамики заказов.
    - Топ популярных товаров (по количеству в заказах).
    - Распределение товаров по категориям.

## 4. UI/UX Концепция
- **Стиль:** Сохранение темной темы "Industrial Precision" (Space Grotesk + Inter).
- **Интерактивность:** Плавные переходы между шагами мастера, индикаторы загрузки, всплывающие уведомления о сохранении.
- **Редактирование:** Кнопка редактирования в таблице товаров открывает Мастер в режиме редактирования.

## 5. Техническая реализация
- **Frontend:** HTML5, Tailwind CSS, Vanilla JS.
- **Backend:** Node.js (Express) + Supabase (PostgreSQL).
- **Безопасность:** Доступ только для пользователей с ролью `admin` через проверку JWT токена.

## 6. План проверки (Success Criteria)
1. Товар успешно создается через Мастер (и "с нуля", и через "клон").
2. Цена 10 выбранных товаров меняется одной операцией на +5%.
3. Заявка с сайта мгновенно появляется в разделе "Лиды".
4. Все карточки дашборда перенаправляют на нужные вкладки.
