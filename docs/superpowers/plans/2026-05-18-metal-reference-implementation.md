# Справочник «Размеры и вес»: План реализации

> **Для агентных исполнителей:** ТРЕБУЕМЫЙ ДОП-НАВЫК: Используйте superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans для пошагового выполнения этого плана. Шаги используют синтаксис чекбоксов (`- [ ]`) для отслеживания.

**Цель:** Создать многостраничный справочник теоретических весов металлопроката в индустриальном стиле Iron Woodman.

**Архитектура:** 
- `spravka.html`: Точка входа с сеткой категорий.
- `spravka_*.html`: Страницы с таблицами ГОСТ.
- Использование общего хедера/футера через `js/shared-ui.js`.

**Стек:** HTML5, Tailwind CSS, Material Symbols.

---

### Задача 1: Главная страница справочника (`spravka.html`)

**Файлы:**
- Создать: `spravka.html`

- [ ] **Шаг 1: Создать структуру `spravka.html`**
Использовать стандартный шаблон Iron Woodman с подключением `shared-ui.js`.

- [ ] **Шаг 2: Реализовать Hero-секцию и Bento-сетку категорий**
Сетка должна содержать карточки: Арматура, Балка, Швеллер, Уголок, Лист, Трубы, Квадрат/Круг. Каждая карточка — ссылка.

- [ ] **Шаг 3: Коммит**
```bash
git add spravka.html
git commit -m "feat: add main reference hub page (spravka.html)"
```
